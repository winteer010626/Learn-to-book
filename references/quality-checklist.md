# 漏项排查与零错误质检清单

## 一、逐页漏项排查（每张上传照片都要过一遍）

- [ ] 每张图表：完整数据表（全部类别+数值+名次）、样本量/时间/口径、来源；配套每一问都有标准答案
- [ ] 每个 Einstieg / 讨论 / Berichten 提示，全部列出
- [ ] 每篇阅读：标题匹配、选择、填空全部给答案；判断/选择题写“理由”
- [ ] 每张配图/照片的配对答案
- [ ] 每个口语练习，包括第二个“Austausch / Tauschen Sie sich aus”提示
- [ ] 听力题：列出全部问题；**答案依赖音频，无音频绝不编造**，统一标注“需要音频”
- [ ] 图表与题干里的高频词（如 Gesundheit、Umwelt、Kultur）补进词汇表

## 二、考点覆盖

- [ ] 词汇按词性/主题分类，名词带冠词复数，动词标配格
- [ ] 语法：概念、全部时态/形式、转换步骤、课本原例、易错点；补该级别高频延伸
- [ ] 口语：每个可能话题都有成段模板（Einleitung/Pro/Contra/Meinung/Schluss）
- [ ] 写作：框架 + Redemittel + 完整范文 + 加分句 + 自查清单

## 三、德语零语法错误（用户“不能背错误的东西”）

- [ ] 动词位置：主句 V2，从句（dass/weil/während、间接问句）限定动词末尾
- [ ] 格与介词：及物 +A、+D、sich；von+人(D)、durch+手段
- [ ] 主谓一致、形容词词尾、名词复数与冠词
- [ ] 被动态：过程被动 werden+PII；完成时 sein+PII+**worden**（不是 geworden）；情态动词被动 PII+werden 末尾
- [ ] 数字/百分比照抄来源，分清单位（% 还是 Millionen）；核对“großer Abstand / gleichauf”等表述是否与数据相符
- [ ] 任何无法核实的内容不写入，或显式标注待确认
